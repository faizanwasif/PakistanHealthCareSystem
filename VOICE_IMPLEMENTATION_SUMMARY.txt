TECHNICAL IMPLEMENTATION
=======================

Backend Components:
- UrduASR class with ULCA API integration
- translate_to_english() function using Gemini
- translate_to_urdu() function using Gemini
- Voice endpoints with authentication
- File upload and temporary storage

Frontend Components:
- MediaRecorder API for audio capture
- FormData for file upload
- Voice button with recording states
- Bilingual message display
- Error handling and user feedback

Voice Processing Flow:
1. User clicks microphone button
2. Browser requests microphone permission
3. Audio recording starts (visual feedback)
4. User clicks stop button
5. Audio blob sent to /api/voice/chat
6. Server transcribes Urdu audio
7. Translation to English for processing
8. CrewAI agents process healthcare query
9. Response translated back to Urdu
10. Bilingual response displayed
